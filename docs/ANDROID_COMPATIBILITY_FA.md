# Android 6 و Android TV

حداقل واقعی بسته Android برابر API 23 است. نسخه Flutter این پروژه و اکشن انتشار باید 3.32.8 باشد؛ موتور نسخه‌های جدیدتر حداقل API 24 دارد. ابزار ساخت AGP 8.12.1، Kotlin 2.2.20، Gradle 8.14 و NDK 28.2.13676358 است. compileSdk/targetSdk برابر 37 باقی می‌ماند.

برای ساخت محلی، مسیر SDK را با MBN_FLUTTER_SDK یا پارامتر FlutterSdk اسکریپت انتشار مشخص کنید. ابزار انتشار نسخه SDK را پیش از ساخت بررسی می‌کند. APKهای ARM32 و ARM64 منتشر می‌شوند؛ برای تلویزیون ARM فایل مطابق معماری دستگاه را نصب کنید.

Android پایین‌تر از 12، دستگاه کم‌رم و تلویزیون به‌صورت محلی و خودکار حالت سبک دارند. این انتخاب با همگام‌سازی حساب به دستگاه دیگر منتقل نمی‌شود: تصاویر کارت‌ها کوچک‌تر دیکد و حافظه تصاویر به 48 MiB محدود می‌شود؛ پس‌زمینه متحرک، حرکت خودکار بنرها، موج دکمه جابه‌جایی و shimmer دائمی غیرفعال است. انیمیشن لمس و حرکت کوتاه بین صفحات باقی می‌ماند. روانی نهایی به پردازنده، حافظه، کدک و شبکه دستگاه نیز بستگی دارد.

تلویزیون با FEATURE_LEANBACK یا حالت UI_MODE_TYPE_TELEVISION شناسایی می‌شود. برنامه بنر و ورودی Leanback دارد و به لمس یا سنسور شتاب‌سنج نیاز ندارد. کنترل‌های استاندارد فرم ورود، تنظیمات، جستجو، دانلودها و پنجره‌ها با فوکوس قابل استفاده‌اند؛ کارت‌ها و کاور پیش‌نمایش نیز دکمه OK دارند. در پلیر با دکمه‌های مخفی، راست/چپ جابه‌جایی پخش، OK پخش/توقف و بالا/پایین نمایش کنترل‌ها است؛ با کنترل‌های آشکار، جهت‌ها فوکوس را بین دکمه‌ها جابه‌جا می‌کنند. Back پنجره یا صفحه را می‌بندد.

نسخه محلی flutter_secure_storage همان قالب رمزنگاری و نام کلیدهای نسخه 11.1.0 را حفظ می‌کند؛ فقط حداقل Android و وابستگی Tink برای API 23 سازگار شده‌اند. تغییر قالب یا برگشت به نسخه 9 مجاز نیست زیرا اطلاعات ورود کاربران نصب‌شده را از دست می‌دهد.

اعتبارسنجی:

- flutter analyze lib test integration_test
- flutter test
- flutter test integration_test/android_compatibility_test.dart -d DEVICE
- python tools/verify_android_apk.py APK

تست روی دستگاه، رمزنگاری خواندن/نوشتن/حذف، فایل‌ها، پروفایل سخت‌افزار و پخش ویدیو را بررسی می‌کند. اکشن انتشار حداقل SDK و الزامات TV را از manifest داخل هر APK بررسی می‌کند؛ تغییر minSdk در فایل Gradle به‌تنهایی کافی نیست.

اعتماد HTTPS در Android 6 تا 11 با ریشه‌های رسمی ISRG X1/X2 تکمیل می‌شود؛ بررسی زنجیره و نام میزبان فعال می‌ماند. این تنظیم هم در Dart و هم در Application اندروید برای دانلودهای پس‌زمینه اجرا می‌شود. versionCode برابر 2000 به‌علاوه شماره build است تا نصب‌های موجود با کدهای 2037/2051 قابلیت ارتقا داشته باشند.

برای تست پخش، کلیپ H.264 Baseline/AAC شش‌ثانیه‌ای را با نام mbn-compatibility.mp4 تولید و با tools/serve_compatibility_media.py از پوشه کلیپ سرو کنید. شبیه‌ساز از http://10.0.2.2:8765 به آن دسترسی دارد و سرور Range پخش را پشتیبانی می‌کند. گزینه MBN_QA_EXPECT_SDK=23 نسخه واقعی دستگاه، MBN_QA_EXPECT_TV=true شناسایی TV و MBN_QA_HEALTH=true اتصال HTTPS سرور با Dart و دانلودر native را بررسی می‌کند. HTTP_PROXY/HTTPS_PROXY نباید اتصال DDS محلی را به پروکسی بفرستند.

اکشن ویندوز روی windows-2022 اجرا می‌شود. اسکریپت محلی در سیستم دارای Visual Studio 2026 در صورت شکست تشخیص IDE توسط Flutter 3.32، از CMake همان IDE و پوشه ساخت جدا استفاده می‌کند.
