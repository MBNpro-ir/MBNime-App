# انتشار اصلاحات پارتی — ۲۰۲۶/۱۰/۲۴

کاربر انتشار ده اصلاح پارتی و به‌روزرسانی سایت‌ها و پنل را تأیید کرد و خواست بررسی لگ ابتدای ویدیو فعلاً کنار گذاشته شود.

نسخه‌های هدف: موویی **1.1.1+91**، انیمه **2.1.1+78** و پنل اصلی **1.1.1+3**. وضعیت این سند هنگام آماده‌سازی: **تست محلی موفق؛ انتشار و بررسی سرور در حال انجام**. نتیجهٔ نهایی با شناسهٔ اکشن‌ها و شواهد سایت زنده تکمیل می‌شود.

## دامنه

ده مورد پارتی شامل انتخاب جداگانهٔ فصل/قسمت، چرخهٔ جهت پلیر، سوایپ پاسخ، منوی واکنش در فضای خالی، چت مشترک دو اپ، یافتن و برجسته‌کردن پیام اصلی، آیدی برابر نام کاربری سرور، هشدار و حذف تاریخچهٔ خصوصی پس از قطع دوستی/بلاک، وضعیت بارگذاری و خطا و صفحهٔ کامل عنوان پیاده‌سازی شده‌اند. [جزئیات و قرارداد مهاجرت](BUGFIX_PREVIEW_20261024_FA.md).

ابزارهای native تشخیص فریم، تغییرات آزمایشی runner ویندوز و probe محلی در این انتشار وارد نمی‌شوند. [رخداد لگ](../performance/VIDEO_STUTTER_20261024_FA.md) باز و با درخواست کاربر کنار گذاشته شده است.

## اعتبارسنجی پیش از انتشار

- موویی: ۳۸۰ تست موفق، یک skip؛ انیمه: ۳۹۲ تست موفق، یک skip.
- هر بستهٔ پارتی ۱۶ تست و هر اپ پنج تست جهت/مالکیت پلیر؛ مجموعهٔ هدفمند ۲۱ تست در هر اپ موفق است.
- بک‌اند: ۱۴۵ تست شامل یک skip؛ پنل: ۲۳ تست موفق.
- تحلیل فایل‌های اصلاح‌شده بدون خطا؛ ساخت پیش‌نمایش وب و APK debug هر دو اپ موفق است.
- تست تازهٔ دستگاه فیزیکی Android، تلویزیون یا iPhone انجام نشده است. iOS از مسیر وب/PWA منتشر می‌شود؛ این کار IPA تولید نمی‌کند.

## برنامهٔ استقرار

قبل از تغییر سرور، از SQLite با API backup و از backend/dashboard نسخهٔ پشتیبان گرفته می‌شود. مهاجرت روی یک کپی واقعی DB، حفظ کاربران و پیام‌ها، کلیدهای خارجی و idempotence کنترل می‌شود. پس از استقرار، API احرازهویت‌شده با حساب‌های موقت مصنوعی، هش فایل‌ها، سلامت سرویس و نسخهٔ سایت‌ها بررسی می‌شوند. حساب‌های واقعی برای تست دوستی یا حذف چت استفاده نمی‌شوند.
