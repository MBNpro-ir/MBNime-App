# اتصال بخش هنتای ایران

اتصال در `lib/services/hentai_iran_api.dart` فقط خواندنی است و از API عمومی وردپرس سایت (`/wp-json/wp/v2/anime`) برای فهرست و از صفحه عنوان برای لینک‌های امضاشده قسمت‌ها استفاده می‌کند.

- گزینه «هنتای ایران • +۱۸» در منوی کشویی با رنگ قرمز نمایش داده می‌شود.
- اولین ورود با دیالوگ غیرقابل‌ردکردنِ هشدار سنی محافظت می‌شود و تأیید در `SharedPreferences` ذخیره می‌گردد.
- جست‌وجو، کاور، جزئیات، قسمت‌ها و پلیر داخلی/دانلود موجود برنامه به‌صورت مشترک استفاده می‌شوند.
- لینک‌های ویدیو کپی یا روی سرور برنامه ذخیره نمی‌شوند؛ چون لینک‌های سایت زمان‌دار هستند، هنگام بازکردن جزئیات دوباره استخراج می‌شوند.

قبل از انتشار عمومی، مجوز بازنشر محتوا، قوانین سایت مرجع، سیاست فروشگاه‌ها و کنترل والدین پلتفرم هدف را جداگانه بررسی کنید. تأیید سنی محلی به‌تنهایی احراز هویت قانونی سن نیست.
