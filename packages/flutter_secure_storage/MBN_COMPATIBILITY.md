Based on flutter_secure_storage 11.1.0 (MIT). Android API 23 uses the same RSA OAEP / AES GCM storage and aliases as existing releases. minSdk is 23; the migration-only Tink dependency uses 1.16.0, compatible with API 23. Newer Android cryptographic/biometric APIs retain upstream SDK guards. Do not revert to storage 9.x or change cipher defaults: existing device tokens must survive updates.
