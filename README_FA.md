# MBNime 1.5.0

برنامهٔ تماشای ویدئو برای Android و Windows با رابط فارسی و راست‌به‌چپ.

- پلیر داخلی، زیرنویس، تصویر در تصویر Android و کنترل با کیبورد در Windows.
- نمایش چندقسمتی در هر ردیف و انتخاب روش پخش یا دانلود.
- دانلودر داخلی با صف، توقف/ادامه، تلاش مجدد، Wi-Fi، تنظیم هم‌زمانی و اعلان بی‌صدا با کاور.
- ذخیرهٔ مرتب در Downloads/MBNime بر اساس نوع، عنوان و فصل یا کیفیت.
- پخش تلویزیونی و دسترسی به تنظیمات Wireless Display / Miracast سیستم.
- دانلود خودکار بروزرسانی و نصب با تأیید، بررسی صحت فایل، آپدیتر C++ ویندوز با بازگشت نسخهٔ قبلی.

برای راهنمای کنترل پلیر با کیبورد F1 را بزن. اتصال بی‌سیم نیازمند پشتیبانی نمایشگر و دستگاه است و ممکن است تمام صفحه و اعلان‌های آن را نمایش دهد.

برای ذخیرهٔ مستقیم دانلودهای Android دسترسی مدیریت فایل، و برای اعلان‌ها اجازهٔ اعلان لازم است. ادامهٔ دانلود به پشتیبانی سرور بستگی دارد. برنامهٔ Force stop شده تا اجرای دوباره نمی‌تواند دانلود را ادامه دهد.

برای توسعه، README و برای ساخت نسخهٔ امضاشده [راهنمای انتشار](docs/RELEASES_FA.md) را بخوان. کلید سرویس در زمان بیلد با MBN_API_KEY داده می‌شود و هیچ اطلاعات ورود شخصی یا کلید امضایی داخل سورس نیست. از فایل‌های امضای خصوصی همیشه پشتیبان امن بگیر.

برای اجرای دیباگ روی گوشی متصل، از `./Run-MBNime-Android-Debug.ps1` استفاده کن. این اجرا کلید سرویس را از فایل محلی و نادیده‌گرفته‌شدهٔ `.signing/api-config.json` تزریق می‌کند؛ اجرای مستقیم `flutter run` این کلید را ندارد. پس از تغییر تنظیمات بیلد، اجرای قبلی را کامل متوقف و دوباره اجرا کن؛ Hot Reload کافی نیست.
